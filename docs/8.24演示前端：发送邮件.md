可以按“邮件起草与发送审批”来演示。建议先做安全演示：系统会完整展示 Agent 分工、手工连线、TODO、工具调用与运行总结，但不会真的把邮件发出去。

1. 先到“工具目录”确认已有“任务记录（task_note）”工具。它用于演示工具调用轨迹，不会访问外部系统。

2. 进入“Agent 编排”，依次创建 3 个 Agent。

| Agent | 职责描述 | 系统提示词 |
|---|---|---|
| 邮件需求分析师 | 提取收件人、主题、目的、语气与待确认信息 | `分析用户的邮件需求，提取收件人、主题、目的、关键信息和风险点。信息不足时明确列出待确认项。输出结构化要点，供下游 Agent 使用。` |
| 邮件撰写助手 | 起草清晰、专业的邮件 | `根据上游需求分析，撰写可直接发送的中文邮件草稿。包含主题、称呼、正文、行动项和落款。不得编造未知事实；缺失信息用【待确认】标记。` |
| 发送前审核员 | 检查邮件并输出发送建议 | `审核邮件草稿：检查收件人、事实准确性、语气、敏感信息和行动项。输出“建议发送”或“需要修改”，并给出最终邮件版本。将审核结论记录为可审计说明。` |

3. 在画布中按顺序连线：

```text
邮件需求分析师 → 邮件撰写助手 → 发送前审核员 → END
```

点击第一个 Agent，然后在右侧点击“设为入口”。

4. 演示工具调用：选中“发送前审核员”，在右侧“工具授权”中勾选“任务记录”。这样运行时会显示该 Agent 调用了工具及其返回内容。

5. 进入“工作流”，点击“保存当前编排”：

- 名称：`邮件起草与发送审核`
- 标签：`邮件,审批,演示`
- 描述：`从需求分析、邮件起草到发送前审核的三阶段流程`

6. 进入“运行中心”→“新任务”，选择刚保存的工作流，输入：

```json
{
  "input": "请给产品团队发送一封邮件：通知大家本周五下午 3 点召开 AgentForge 演示评审会，地点为 A301 会议室；请相关负责人提前准备 5 分钟演示材料。语气专业、简洁。"
}
```

运行时你会看到：

- 开始生成 TODO 和执行计划；
- 依次切换到三个 Agent；
- 审核 Agent 调用“任务记录”工具；
- 所有过程流式展示；
- 结束后自动收起过程，并输出最终总结、总耗时与完成时间。

注意：当前项目还没有真实邮件发送能力。即使你在“工具目录”登记一个“发送邮件”描述，它也不会获得电脑或邮箱权限，更不会自动发信。要真实发送邮件，需要后端新增受控的 `email_send` 适配器，并接入 SMTP、SendGrid、Resend 或企业邮箱 API；该工具应标记为高风险，运行时必须人工批准后才发送。
